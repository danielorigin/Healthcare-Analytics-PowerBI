\# Healthcare Analytics Dashboard using Power BI



\## Project Overview



This project demonstrates an end-to-end Business Intelligence solution developed using Python and Power BI.



The objective is to transform raw healthcare data into actionable insights for hospital management through interactive dashboards.



The project covers the complete analytics lifecycle including:



\- Data Cleaning using Python

\- Data Transformation

\- Data Modeling

\- DAX Calculations

\- Interactive Dashboard Development

\- Business Insights

\- Executive Reporting



\---



\## Business Problem



Hospitals generate large volumes of patient, billing and operational data.



Without proper visualization, management cannot easily identify



\- Patient admission trends

\- High-cost medical conditions

\- Doctor workloads

\- Insurance performance

\- Financial performance

\- Patient demographics



This project converts raw healthcare data into executive dashboards that support data-driven decision making.

\## Key Insights



\- Arthritis generated the highest billing.

\- Female patients represented approximately 44% of admissions.

\- Billing increased with longer patient stays.

\- Insurance providers contributed significantly to hospital revenue.

\- Hospital workloads were evenly distributed.
